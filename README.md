# BlakeBot - Discord Bot

Discord бот для управления контрактами и бонусами, переведенный с C# на Node.js.

## Установка

1. Установите зависимости:
```bash
npm install
```

2. Настройте `config.json` с вашим токеном бота:
```json
{
  "token": "YOUR_BOT_TOKEN_HERE",
  "testGuildId": "YOUR_TEST_GUILD_ID",
  "frame29Url": "https://...",
  "frame30Url": "https://..."
}
```

3. Запустите бота:
```bash
npm start
```

## Команды

- `/start_contract` - Открыть запись на контракт (только для определенных ролей)
- `/send_bonus_message` - Отправить сообщение о бонусах (только админ)
- `/send_bonus_info` - Отправить описание бонусов (только админ)

## Функции

- **Система контрактов**: Создание записей на контракты с таймером, автоматическое закрытие, управление участниками
- **Система бонусов**: Формы заявок на бонусы за приглашения
- **Автоматическая выдача ролей** новым участникам сервера
- **Keep-alive**: Автоматический пинг каждые 5 минут для предотвращения сна на Railway
